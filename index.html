How it works

An aggregator of aggregators.

The problem

Video models like Seedance, Kling, Veo, Wan and MiniMax are sold through many API “aggregators” (fal.ai, Replicate, Atlas Cloud, Runware, Kie.ai and others). Each one sets its own price, runs its own launch sales, and bills in its own units — per second, per clip, per credit, per million tokens. The cheapest place for one model is often the most expensive for another, and it changes week to week.

What this site does

It reads all 10 aggregators every day, converts every quote to the same unit — USD per minute of generated footage at 720p (768p for the MiniMax H3 family) — keeps audio-on and audio-off variants separate, notes each sale and its deadline, and publishes the winner per model. The table at the top is the summary; the charts show the spread; the JSON feed lets software make the choice automatically.

The daily research run

  1. 06:17 New York time, a scheduled job wakes up (GitHub Actions, free).
  2. For every model × aggregator pair it asks the provider's own machine-readable source first — Atlas Cloud's free quote endpoint, fal.ai's and OpenRouter's model APIs, WaveSpeed's catalog, Runware's model schema, the price block embedded in Replicate and Kie.ai pages.
  3. Where no such source exists it opens the page (with a headless browser when it needs JavaScript) and lets Claude read the price for exactly that model, tier, resolution and audio setting — and, if the page moved, search the provider's site — so a redesign does not break the feed.
  4. Every figure is normalized to $/min, sanity-checked against yesterday (a 5× jump is flagged, not published), and dated sales that ended are switched to the regular price.
  5. It recomputes the cheapest aggregator per model, writes a dated snapshot for the history charts, rebuilds this page and publishes it.

First edition — built from a live multi-agent research pass; the daily robot takes over from here.

Reading the numbers honestly

“Per minute” means accumulated generated footage, not one continuous 60-second clip — the Max clip column shows the longest single clip each endpoint allows. Prices for token-billed models are estimates for a 16:9 output at the stated resolution. Provider-specific tiers (Kie's “Lite mode” for Veo, Atlas's “Developer” tier for Grok) are kept as their own rows because they are not guaranteed to be the same product as the standard API. Quality is not ranked here — only price. Every quote links to its source, carries the date it was verified, and is flagged when the robot could not re-verify it.

FEED = "https://bennygoldstein.github.io/discount-aggregator/data/cheapest.json"
feed = requests.get(FEED, timeout=10).json()

best = feed["models"]["mini"]          # Seedance 2.0 Mini (ids are in the feed)
print(best["cheapest_aggregator"],       # e.g. "Atlas Cloud"
      best["usd_per_min_720p"],          # e.g. 1.45
      best["endpoint_id"])               # the model id to pass to that API

# Now call that aggregator's API:
api = best["aggregator"]["api_base_url"]
docs = best["aggregator"]["api_docs_url"]
# → build the request per `docs`, using best["endpoint_id"]
